📋 הוראות חיבור Firebase

שלב 1: היכנסו ל-console.firebase.google.com
שלב 2: צרו פרויקט חדש → בחרו "Realtime Database"
שלב 3: לחצו "Add App" → Web → קבלו את ה-Config
שלב 4: הכניסו את ה-Config בשדות למטה ולחצו חבר
שלב 5: שנו Rules ב-Database ל: {"rules":{".read":true,".write":"auth != null"}}
